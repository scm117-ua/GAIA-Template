# Product Requirements Document (PRD)

## 1. Product Overview
**Product Name:** GAIA Template Project (Vintage Story Utilities)
**Vision:** Provide useful utilities for Vintage Story players, starting with an Alloy Calculator to simplify crafting complex alloys.

## 2. Global Users & Roles
- **Player (USER):** The main user of the application. Wants to calculate alloy ratios efficiently.

## 3. Core Features (Summary)

### 3.1 Alloy Calculator
**Scope:** A tool to calculate the necessary nuggets and ingots to create specific alloys based on in-game ratios.
**Value:** Reduces math errors and wasted materials for players when crafting complex alloys like Bismuth Bronze or Black Bronze.
**Access:** Public.

## 4. Technical Constraints
- Must be a web-based application (frontend).
- Must adhere to Vintage Story game mechanics (ratios).
